## 第 0 章 — 建立 Maven Web 專案

### 步驟 0.1：建立目錄結構

```
mvweb1002/
├── pom.xml
└── src/
    └── main/
        ├── java/          ← 先建空的，後面會用到
        └── webapp/
            └── WEB-INF/   ← 先建空的
```

```powershell
New-Item -ItemType Directory -Force -Path "src\main\java","src\main\webapp\WEB-INF"
```

### 步驟 0.2：撰寫 pom.xml

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
  <modelVersion>4.0.0</modelVersion>

  <groupId>demo1002</groupId>
  <artifactId>mvweb1002</artifactId>
  <version>0.0.1-SNAPSHOT</version>
  <packaging>war</packaging>      <!-- ★ 關鍵：打成 WAR，不是 jar -->

  <name>mvweb1002 Maven Webapp</name>

  <properties>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    <maven.compiler.source>21</maven.compiler.source>
    <maven.compiler.target>21</maven.compiler.target>
  </properties>

  <dependencies>
    <!-- JSTL API：編譯期需要標籤類別 -->
    <dependency>
      <groupId>jakarta.servlet.jsp.jstl</groupId>
      <artifactId>jakarta.servlet.jsp.jstl-api</artifactId>
      <version>3.0.0</version>
    </dependency>
    <!-- JSTL 實作：執行期真正做事的類別 -->
    <dependency>
      <groupId>org.glassfish.web</groupId>
      <artifactId>jakarta.servlet.jsp.jstl</artifactId>
      <version>3.0.1</version>
    </dependency>
  </dependencies>

  <build>
    <finalName>mvweb1002</finalName>   <!-- 產出 mvweb1002.war -->
  </build>
</project>
```

### 為什麼 JSTL 要兩個 dependency？

| dependency | 角色 | 少了會怎樣 |
|-----------|------|-----------|
| `jakarta.servlet.jsp.jstl-api` | **介面**（宣告有哪些標籤） | Eclipse 報紅字，說找不到標籤 |
| `org.glassfish.web:jakarta.servlet.jsp.jstl` | **實作**（標籤真的怎麼跑） | 執行時拋 `ClassNotFoundException` 或標籤沒反應 |

兩者缺一不可。

> **注意**：`<scope>` 不要寫 `provided`。本專案的 JSTL 需要被打進 `WEB-INF/lib`，
> 預設的 `compile` scope 才是正確的。

## 第 1 章 — 第一個 JSP：`index.jsp`

### 目標

讓瀏覽器顯示 `Hello World!`。

### 動手寫

建立 `src/main/webapp/index.jsp`：

```jsp
<html>
<body>
<h2><%= "Hello World!" %></h2>
</body>
</html>
```

### 這行程式在做什麼？

JSP 檔案其實**不是**程式碼，它是一個 HTML 範本。
當有人請求這個網址時，Tomcat 會把它**翻譯成 Java Servlet** 再編譯執行。

`<%= ... %>` 是 **JSP 運算式（expression）**，
等價於 Java 的 `out.print(...)`，也就是「把結果印到 HTML 輸出流」。

翻譯後的概念上等於：

```java
out.print("<html><body><h2>");
out.print("Hello World!");           // ← 這是 <%= "Hello World!" %> 翻譯出來的
out.print("</h2></body></html>");
```

**重點**：HTML 原封不動輸出，只有 `<%= %>` 會被執行。

### 驗證

啟動 Tomcat 後開啟 `http://localhost:8080/mvweb1002/`，看到 `Hello World!` 就成功了。

### ⚠️ 為什麼原專案的 index.jsp 沒寫 page 指令？

因為沒有宣告 `pageEncoding`，JSP 預設會用 **ISO-8859-1** 讀取來源檔。
現在只輸出 ASCII 字元所以沒事，一旦你加入中文（例如 `"你好"`）就會整片亂碼。

**正確寫法**（建議從現在開始就這樣寫）：

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<body>
<h2>Hello World! 你好世界</h2>
</body>
</html>
```

## 第 2 章 — 標準骨架與兩個必要指令

從這一章起，每個 JSP 都用這個骨架：

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<%@ taglib prefix="c" uri="jakarta.tags.core" %>
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>我的頁面</title>
</head>
<body>
    <!-- 內容寫這裡 -->
</body>
</html>
```

### 指令 1：`page`

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
```

| 屬性 | 決定什麼 |
|------|---------|
| `pageEncoding="UTF-8"` | 讀這個 .jsp 檔時用什麼編碼解讀 |
| `contentType="text/html; charset=UTF-8"` | 送到瀏覽器時，用什麼型態與編碼宣告 |

### 指令 2：`taglib`

```jsp
<%@ taglib prefix="c" uri="jakarta.tags.core" %>
```

這行的意思是：「我要使用 `jakarta.tags.core` 這個函式庫，
以後用 `c:` 這個前綴呼叫它。」

| 函式庫 | URI | 前綴慣例 | 用途 |
|--------|-----|---------|------|
| core | `jakarta.tags.core` | `c` | 設變數、輸出、判斷、迴圈 |
| fmt | `jakarta.tags.fmt` | `fmt` | 數字／日期格式化 |
| functions | `jakarta.tags.functions` | `fn` | 字串與集合函式 |

### 章節重點

1. `<%= %>` 會執行並輸出；其他文字原封不動輸出。
2. 兩種編碼都要設 UTF-8，否則中文亂碼。
3. 用 JSTL 前一定要先 `taglib` 宣告，否則容器不認得那些標籤。

## 第 3 章 — 設定變數：`jstl1.jsp`

### 目標

學會把「張小明」這個值存進變數，再輸出出來。

### 動手寫

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<%@ taglib prefix="c" uri="jakarta.tags.core" %>
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>JSTL Variables</title>
</head>
<body>
<%-- 設定簡單變數 --%>
<c:set var="name" value="張小明" />

<h1>
    名字: ${name}
</h1>
</body>
</html>
```

### 逐行拆解

| 行 | 說明 |
|----|------|
| `<%-- 註解 --%>` | **JSP 註解**，不會出現在 HTML 原始碼中（`<% /* */ %>` 也行，但會留在輸出裡） |
| `<c:set var="name" value="張小明" />` | 建立變數 `name`，值為字串 `張小明` |
| `${name}` | **EL 運算式**，取出 `name` 的值輸出 |

### `${}` 是什麼？

`${}` 是 **EL（Expression Language）** 語法。
它是 JSTL 的靈魂 —— 一種寫在 HTML 裡、能在執行期求值的迷你語言。

```
${name}          → 取名為 name 的屬性
${name.length}   → 取它的長度
${num % 2}       → 做算術運算
${score >= 90}   → 做比較，回傳 true/false
```

`${}` 內的變數名稱，JSP 會依序到這些地方找（稱為 EL 的作用域）：

```
Page  →  Request  →  Session  →  Application  →  null
(c:set 預設          (param)     (session)      (initParam)
 在這裡)
```

`c:set` **沒有指定 scope 時預設是 Page scope**，也就是只在这个页面有效。

### 常見錯誤

| 錯誤寫法 | 結果 |
|---------|------|
| `<c:set value="張小明" var="name">` | 少了 `/` 沒關閉 → 報錯 |
| `${Name}`（大寫 N） | 輸出空白（EL **大小寫敏感**） |
| `${name }`（中間有空格） | 其實合法，EL 會忽略 |

### 驗證

開啟 `/jstl1.jsp` → 顯示 `名字: 張小明`

## 第 4 章 — 表單與參數接收

這個範例要兩個檔案，是本專案第一個「有流程」的案例。

### 4.1 表單頁：`nameage.html`

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>Name Age Form</title>
</head>
<body>
<form action="jstl2.jsp" method="post">
   名字:<input type="text" name="name" value="Mary"/> <br/>
   年紀:<input type="text" name="age" value="20"/> <br/>
   <input type="submit"/>
</form>
</body>
</html>
```

### 表單重點

| 屬性 | 說明 |
|------|------|
| `action="jstl2.jsp"` | 送到同層的 `jstl2.jsp`（相對路徑） |
| `method="post"` | 用 POST 送出（資料在 request body，不會出現在網址列） |
| `name="name"` | ★ **這個欄位送出去時的參數名稱** |

「預設值」`value="Mary"` / `value="20"` 是為了讓你不用輸入就能直接按送出看效果。

### 4.2 接收頁：`jstl2.jsp`

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<%@ taglib prefix="c" uri="jakarta.tags.core" %>
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>Name Age</title>
</head>
<body>
<c:set var="name" value="${param.name}" />
<c:set var="age" value="${param.age}" />
<h2>
   <p>你輸入資料</p>
   Name: ${name} <br/>
   Age : ${age}
</h2>
</body>
</html>
```

### `${param.xxx}` 是什麼？

`param` 是 EL 的**隱式物件**，它代表「這一筆 HTTP 請求帶的所有參數」。

```
param.name  →  表單裡 name="name"  的欄位值
param.age   →  表單裡 name="age"   的欄位值
param.action →  表單裡 name="action" 的欄位值（如果有的話）
```

`param` 同時支援 GET 的查詢字串與 POST 的表單參數，
所以網址寫 `jstl2.jsp?name=Tom&age=30` 也一樣能取到。

### 完整請求流程

```
瀏覽器                                        Tomcat
  │                                              │
  │  GET /mvweb1002/nameage.html                 │
  ├─────────────────────────────────────────────►│
  │◄─────────────────────────────────────────────┤
  │      顯示表單（預設 Mary / 20）              │
  │                                              │
  │  使用者改成 Tom / 25，按「送出」              │
  │  POST /mvweb1002/jstl2.jsp                    │
  │  body: name=Tom&age=25                       │
  ├─────────────────────────────────────────────►│
  │                              param.name = Tom│
  │                              param.age  = 25 │
  │                              ${name} → Tom  │
  │                              ${age}  → 25   │
  │◄─────────────────────────────────────────────┤
  │      顯示「Name: Tom / Age: 25」            │
```

### 驗證

1. 開 `/nameage.html`
2. 把名字改成 `Tom`、年紀改成 `25`
3. 按送出 → 看到 `Name: Tom` `Age: 25`

## 第 5 章 — 條件判斷：`c:if`

### 目標

判斷 86 是偶數還是奇數。

### 動手寫

```jsp
<c:set var="num" value="86" />

<c:if test="${num%2==0}">
    <p>${num} 偶數</p>
</c:if>
<c:if test="${num%2!=0}">
    <p>${num} 奇數</p>
</c:if>
```

### 逐行拆解

| 片段 | 說明 |
|------|------|
| `${num%2==0}` | `86 % 2 = 0` → `true` → 輸出「86 偶數」 |
| `${num%2!=0}` | `86 % 2 = 0`，`0 != 0` → `false` → 整段跳過 |

### `c:if` 的重要特性

**`c:if` 沒有 `else`。** 這是 JSTL 與 JScriptlet 最大的差異。

想寫 else 有兩種方式：

```jsp
<!-- 方式一：寫兩個 c:if，用相反條件（本專案的做法） -->
<c:if test="${num%2==0}"><p>偶數</p></c:if>
<c:if test="${num%2!=0}"><p>奇數</p></c:if>

<!-- 方式二：用 c:choose（下一章的 jstl4.jsp） -->
```

### 硬編碼數值的技巧

把 `num` 改成 `85` 就能測奇數分支：

```jsp
<c:set var="num" value="85" />
```

> 這是練習專案的常見手法（改完存檔 → 重整頁面）。
> 正式專案應該用 `${param.num}` 從表單拿，或寫成 Servlet/Controller 處理。

## 第 6 章 — 多分支判斷：`c:choose`

### 目標

分數 85 應該判成 B 級。

### 動手寫

```jsp
<c:set var="score" value="85" />
<h2>
   分數:${score}
</h2>
<c:choose>
    <c:when test="${score >= 90}">
        <p>等級：A</p>
    </c:when>
    <c:when test="${score >= 80}">
        <p>等級：B</p>
    </c:when>
    <c:when test="${score >= 70}">
        <p>等級：C</p>
    </c:when>
    <c:otherwise>
        <p>等級：D</p>
    </c:otherwise>
</c:choose>
```

### 逐行拆解

```
score = 85
  ↓
c:when  score >= 90 ?  85 >= 90 ? false → 繼續
  ↓
c:when  score >= 80 ?  85 >= 80 ? true  → ★ 輸出「等級：B」，後面的全部略過
  ↓
（c:when score >= 70、c:otherwise 都不會被檢查）
```

結果：只有一個 `<p>等級：B</p>` 會出現在頁面上。

### `c:choose` 的三條規則

1. `<c:when>` 可以有**任意多個**
2. **由上往下依序判斷，第一個成立的 `when` 就執行**
3. `<c:otherwise>` **最多一個、必須放最後**，前面的 when 都不成立時才執行

### ⚠️ 最容易犯的錯：順序寫反

```jsp
<!-- ❌ 錯誤：>=70 會先命中，85 變成 C -->
<c:when test="${score >= 70}">C</c:when>
<c:when test="${score >= 90}">A</c:when>

<!-- ✅ 正確：門檻由高到低 -->
<c:when test="${score >= 90}">A</c:when>
<c:when test="${score >= 70}">C</c:when>
```

**規則：條件要從嚴格到寬鬆排列。**

### 驗證各種分數

| 把 `score` 改成 | 結果 |
|----------------|------|
| `95` | 等級：A |
| `85` | 等級：B |
| `72` | 等級：C |
| `59` | 等級：D（`otherwise` 生效） |

## 第 7 章 — 實戰：階梯式折扣 `jstlmoney.jsp`

### 目標

金額 25000 元 → 打 9 折 → 22500 元。

### 動手寫

```jsp
<c:set var="money" value="25000" />
<h2>
   金額:${money}
</h2>
<c:choose>
    <c:when test="${money >= 30000}">
        <p>打8折</p>
        <p>${money*0.8}</p>
    </c:when>
    <c:when test="${money >= 20000}">
        <p>打9折</p>
        <p>${money*0.9}</p>
    </c:when>
    <c:when test="${money >= 10000}">
       <p>打95折</p>
        <p>${money*0.95}</p>
    </c:when>
    <c:otherwise>
        <p>不打折</p>
        <p>${money}</p>
    </c:otherwise>
</c:choose>
```

### 逐行拆解

```
money = 25000
  ↓
money >= 30000 ?  false → 繼續
  ↓
money >= 20000 ?  true  → ★ 打9折，25000 * 0.9 = 22500.0
  ↓
（>= 10000 與 otherwise 都被跳過）
```

### 這一章學到的新東西

| 片段 | 說明 |
|------|------|
| `${money*0.8}` | EL **直接做算術運算**，不需要寫 Java 程式碼 |
| 輸出 `22500.0` | EL 裡的數字會被視為 `Double`，所以有 `.0` |

### 為什麼會多一個 `.0`？

EL 的數值運算一律走 `Double`。`25000 * 0.9` 的結果是 `22500.0`。
想顯示成整數：

```jsp
<!-- 方法一：搭配 fmt 四捨五入 -->
<%@ taglib prefix="fmt" uri="jakarta.tags.fmt" %>
<fmt:formatNumber value="${money*0.9}" pattern="#,##0.##" />

<!-- 方法二：取整數部分 -->
${(money*0.9) - ((money*0.9) % 1)}
```

> 實際做金額計算應該交給 `BigDecimal`（避免浮點誤差），
> 這裡是教學示範，別直接拿去算錢。

### 驗證各種金額

| `money` | 折扣 | 結果 |
|---------|------|------|
| `35000` | 打8折 | `28000.0` |
| `25000` | 打9折 | `22500.0` |
| `15000` | 打95折 | `14250.0` |
| `5000` | 不打折 | `5000.0` |

## 第 8 章 — 迴圈：`c:forEach`

### 目標

一次做兩件事：列出水果清單、印出 1 到 5。

### 動手寫

```jsp
<%@page import="java.util.*" %>

<c:set var="fruits" value="${fts}" />
<c:forEach var="fruit" items="${fruits}" varStatus="status">
    <p>${status.index + 1}. ${fruit}</p>
</c:forEach>
<c:forEach begin="1" end="5" var="i">
    <span>${i}</span>
</c:forEach>
```

搭配前面的 scriptlet 產生資料：

```jsp
<%
   List<String> ft = List.of("蘋果", "香蕉", "橘子");
   pageContext.setAttribute("fts", ft);
%>
```

### 用法 A：走訪集合

```jsp
<c:forEach var="fruit" items="${fruits}" varStatus="status">
```

| 屬性 | 說明 |
|------|------|
| `var="fruit"` | 每圈把當前元素存進這個變數 |
| `items="${fruits}"` | 要走訪的集合／陣列 |
| `varStatus="status"` | 進度資訊物件（索引、是否第一個…） |

`varStatus` 常用屬性：

| 屬性 | 意義 | 第 1 圈的值 |
|------|------|-----------|
| `status.index` | 0 起始索引 | `0` |
| `status.count` | 1 起始序號 | `1` |
| `status.first` | 是否第一圈 | `true` |
| `status.last` | 是否最後一圈 | `false` |
| `status.loopCount` | 目前是第幾圈（1 起算） | `1` |

所以 `${status.index + 1}` 就是在印「第 1 個、第 2 個…」的序號。

`items` 除了 `List`，也可以是 **陣列、Map、Iterator、Enumeration**，
甚至字串（會依字元拆開）。

### 用法 B：數字區間

```jsp
<c:forEach begin="1" end="5" var="i">
```

| 屬性 | 說明 |
|------|------|
| `begin="1"` | 從 1 開始 |
| `end="5"` | 到 5 結束（**包含 5**） |

其他可選屬性：`step`（遞增值）、`varStatus`。

```jsp
<!-- 印出奇數 1,3,5,7,9 -->
<c:forEach begin="1" end="9" step="2" var="i">${i} </c:forEach>
```

### 資料是怎麼「混進來」的？

這個範例示範了 JSP 的 scriptlet 與 JSTL 共存：

```jsp
<%
   List<String> ft = List.of("蘋果", "香蕉", "橘子");
   pageContext.setAttribute("fts", ft);   // 把物件放進 page scope
%>
<c:set var="fruits" value="${fts}" />     <!-- EL 從 page scope 找到它 -->
```

`pageContext.setAttribute(key, value)` 等同於 `<c:set var="key" value="..."/>`。

**更純淨的 JSTL 寫法**（不需要 scriptlet，也不需 `import`）：

```jsp
<c:set var="fruits" value="${['蘋果','香蕉','橘子']}" />
<c:forEach var="fruit" items="${fruits}">${fruit} </c:forEach>
```

> `${['a','b']}` 是 EL 的**清單實值**，語法同 Java 的 `List.of()`。

### 驗證

開啟 `/jstl5.jsp` → 看到

```
1. 蘋果
2. 香蕉
3. 橘子
12345
```

### ⚠️ 原專案這裡有一個 BUG

原始檔案第 3 行是：

```jsp
<%@page import="java.util.*" %>>
                                  ↑ 多了一個 >
```

指令在 `%>` 就結束了，**多出來的 `>` 會被當成一般文字輸出到頁面最上方**，
所以瀏覽器會在 `<!DOCTYPE>` 之前看到一個 `>` 字元。

修法就是把那個多餘的 `>` 刪掉。

## 第 9 章 — 輸出與預設值：`c:out`

### 目標

當變數不存在時，顯示「匿名使用者」而不是一片空白。

### 動手寫

```jsp
<%-- 帶預設值 --%>
<%--  <c:set var="nickname" value="Johnny"/> --%>
<c:out value="${nickname}" default="匿名使用者" />
```

### 逐行拆解

| 片段 | 說明 |
|------|------|
| `<c:out value="..." />` | 安全輸出標籤 |
| `default="匿名使用者"` | 當 `nickname` 為 **null 或空字串** 時顯示這個 |
| 被註解掉的那行 | 故意註解掉，用來示範「變數不存在」的情境 |

### 執行結果對照

| `nickname` 的狀態 | 顯示 |
|------------------|------|
| 沒有設定（null） | `匿名使用者` |
| 設成空字串 `""` | `匿名使用者` |
| 設成 `"Johnny"` | `Johnny` |

把註解拿掉、改成 `<c:set var="nickname" value="Johnny"/>` 就會顯示 `Johnny`。

### `c:out` 還能自動防止 XSS

這是 `${...}` 沒有的能力：

```jsp
<c:set var="html" value="<script>alert('XSS')</script>" />

<c:out value="${html}" />              <!-- 危險：會真的執行 script -->
```

而：

```jsp
<%-- jstlfunc.jsp 的寫法 --%>
${fn:escapeXml(html)}
<!-- 輸出：&lt;script&gt;alert('XSS')&lt;/script&gt;（當文字顯示，不會執行）-->
```

實際開發中，只要輸出的內容「可能來自使用者輸入」，就應該用 `<c:out>` 或 `fn:escapeXml`。

## 第 10 章 — 格式化標籤：`fmt`

要先加宣告：

```jsp
<%@ taglib prefix="fmt" uri="jakarta.tags.fmt" %>
```

### 10.1 數字與貨幣：`jstlformat.jsp`

```jsp
<%-- 貨幣格式 --%>
<fmt:formatNumber value="123456" type="currency" currencyCode="TWD" /><br/>
<fmt:formatNumber value="123456" type="currency" currencyCode="USD" /><br/>
<fmt:formatNumber value="123456" type="currency" currencyCode="JPY" />
<p>
<%-- 千分位 --%>
<fmt:formatNumber value="1234567.89" pattern="#,###.##" />
<p>
<%-- 百分比 --%>
<fmt:formatNumber value="0.856" type="percent" />
```

**`type` 的四種值**：

| `type` | 用途 | 本專案範例輸出（依系統 Locale） |
|--------|------|-------------------------------|
| `number`（預設） | 一般數字 | `123,456.00` |
| `currency` | 貨幣 | `NT$123,456`、`$123,456.00`、`¥123,456` |
| `percent` | 百分比（**自動 ×100**） | `85.600%` |
| （不給） | 用 `pattern` 自訂 | `1,234,567.89` |

**`pattern` 常見符號**：

| 符號 | 意義 | 範例 |
|------|------|------|
| `,` | 千分位逗號 | `#,###` |
| `.` | 小數點 | `#.##` |
| `0` | 必填位數（不足補 0） | `#,##0` |
| `%` | 百分比符號 | `##.##%` |
| `¤` | 貨幣符號 | `¤#,##0.00` |

> **為什麼 TWD 輸出是 `NT$123,456` 而不是 `$123,456`？**
> 因為台灣與美元的符號都是 `$`，JDK 為避免混淆，對 TWD 使用 `NT$`。
> 輸出結果會受**作業系統 Locale** 影響，中文 Windows 通常是 `zh_TW`。

**`value` 可以直接給字串**：`<fmt:formatNumber value="123456" />` 會自動轉成數字再格式化。

### 10.2 日期時間：`jstldate.jsp`

```jsp
<%
   java.util.Date d = new java.util.Date();
   pageContext.setAttribute("now", d);
%>

<%-- 日期格式 --%>
<fmt:formatDate value="${now}" pattern="yyyy-MM-dd" />
<p>
<%-- 時間格式 --%>
<fmt:formatDate value="${now}" pattern="HH:mm:ss" />
<p>
<%-- 日期時間格式 --%>
<fmt:formatDate value="${now}" pattern="yyyy年MM月dd日 HH:mm:ss" />
```

**`value` 必須是 `java.util.Date`**（或 JSTL 定義的子類別）。
傳字串會拋例外，必須搭配 `<fmt:parseDate>` 先轉換。

**`pattern` 是 Java 的 `SimpleDateFormat` 格式**：

| 代碼 | 意義 | 例 |
|------|------|-----|
| `yyyy` | 西元年（4 碼） | `2026` |
| `yy` | 西元年（2 碼） | `26` |
| `MM` | 月（**大寫 M = 月份**） | `10` |
| `dd` | 日 | `02` |
| `HH` | 24 小時制時 | `14` |
| `hh` | 12 小時制時 | `02` |
| `mm` | 分 | `35` |
| `ss` | 秒 | `08` |
| `SSS` | 毫秒 | `123` |

> **最容易搞混的陷阱**：
> `MM` 是月份、`mm` 是分鐘；`HH` 是 24 小時制、`hh` 是 12 小時制。
> 大小寫寫錯，日期就會顯示成奇怪的數字。

### 驗證

- `/jstlformat.jsp` → 看到三種貨幣符號、千分位、85.600%
- `/jstldate.jsp` → 看到今天的日期、三種時間格式

## 第 11 章 — 字串函式與 XSS 防護：`jstlfunc.jsp`

要先加兩行宣告：

```jsp
<%@ taglib prefix="c" uri="jakarta.tags.core" %>
<%@ taglib prefix="fn" uri="jakarta.tags.functions" %>
```

### 動手寫

```jsp
<c:set var="text" value="Hello World 你好世界" />

<%-- 字串長度 --%>
<p>長度：${fn:length(text)}</p>

<%-- 大小寫轉換 --%>
<p>大寫：${fn:toUpperCase(text)}</p>
<p>小寫：${fn:toLowerCase(text)}</p>

<%-- 字串搜尋 --%>
<p>包含 'World'：${fn:contains(text, 'World')}</p>
<p>位置：${fn:indexOf(text, 'World')}</p>

<%-- 字串截斷 --%>
<p>前5字元：${fn:substring(text, 0, 5)}</p>

<%-- 字串取代 --%>
<p>取代：${fn:replace(text, 'World', 'EE')}</p>

<%-- HTML 轉義 --%>
<c:set var="html" value="<script>alert('XSS')</script>" />
<p>轉義：${fn:escapeXml(html)}</p>
```

### 執行結果（`text` = `Hello World 你好世界`）

| 指令 | 結果 | 說明 |
|------|------|------|
| `fn:length(text)` | `16` | `"Hello World"` 11 字 + 空格 1 字 + 中文 4 字 |
| `fn:toUpperCase(text)` | `HELLO WORLD 你好世界` | 中文不受影響 |
| `fn:toLowerCase(text)` | `hello world 你好世界` | |
| `fn:contains(text, 'World')` | `true` | 判斷是否包含 |
| `fn:indexOf(text, 'World')` | `6` | 從 0 開始，`W` 在第 6 個位置 |
| `fn:substring(text, 0, 5)` | `Hello` | **起點包含、終點不包含** |
| `fn:replace(text, 'World', 'EE')` | `Hello EE 你好世界` | |
| `fn:escapeXml(html)` | `&lt;script&gt;alert('XSS')&lt;/script&gt;` | 會在畫面上顯示為文字 |

### `fn` 常用函式

| 分類 | 函式 | 說明 |
|------|------|------|
| 長度 | `fn:length(x)` | 字元數／集合元素數 |
| 大小寫 | `fn:toUpperCase` `fn:toLowerCase` | |
| 搜尋 | `fn:contains` `fn:containsIgnoreCase` `fn:startsWith` `fn:endsWith` `fn:indexOf` | |
| 截取 | `fn:substring(x, begin, end)` `fn:substringBefore` `fn:substringAfter` | |
| 修改 | `fn:replace` `fn:trim` `fn:join` `fn:split` | |
| XML | `fn:escapeXml` | 防 XSS |
| 集合 | `fn:length(list)` | 也可取集合大小 |

### ⚠️ `fn:escapeXml` 的兩件事

**1. 它只轉義 HTML 特殊字元**

| 輸入 | 輸出 |
|------|------|
| `<` | `&lt;` |
| `>` | `&gt;` |
| `&` | `&amp;` |
| `"` | `&quot;` |
| `'` | **不轉義**（單引號原樣輸出） |

所以本例輸出 `alert('XSS')` 的單引號會原樣保留 —— 這是正常的，
因為 `<script>` 內文用單引號包住字串並不會構成新的標籤。

**2. `${...}` 本身不會自動轉義**

這跟其他模板引擎（如 Thymeleaf、Vue）不同。
JSTL/EL 是「原樣輸出」，所以**任何使用者輸入的內容都必須手動轉義**，
否則就是 XSS 漏洞。

## 第 12 章 — 部署設定：`WEB-INF/web.xml`

### 動手寫

```xml
<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xmlns="https://jakarta.ee/xml/ns/jakartaee"
         xsi:schemaLocation="https://jakarta.ee/xml/ns/jakartaee
                             https://jakarta.ee/xml/ns/jakartaee/web-app_6_0.xsd"
         id="WebApp_ID" version="6.0">

  <display-name>mvweb1002</display-name>

  <welcome-file-list>
    <welcome-file>index.jsp</welcome-file>
  </welcome-file-list>
</web-app>
```

### `web.xml` 是什麼？

**Web 應用程式的設定檔**，放在 `WEB-INF/`（瀏覽器無法直接讀取）。

### 兩個重點元素

| 元素 | 說明 |
|------|------|
| `<display-name>` | 顯示在 Tomcat Manager 的應用程式名稱 |
| `<welcome-file-list>` | 使用者只輸入 `/mvweb1002/`（沒有檔名）時，容器依序尋找的檔案 |

### 歡迎頁的尋找過程

```
使用者輸入 http://localhost:8080/mvweb1002/
  ↓
Tomcat 依序檢查 welcome-file-list：
  index.html  →  不存在 ✗
  index.jsp   →  ★ 存在 → 顯示它
```

> 原專案的清單有 8 個項目（`index.html` / `index.jsp` / `index.htm` / `index.xhtml`
> / `default.html` / ... ），這是 Eclipse 骨架的預設值。
> 功能上沒問題，只是冗長。實務上建議只留真正存在的那一個。

### ⚠️ `version="6.0"` 綁定 Tomcat 版本

| `web.xml` version | 需要 Tomcat |
|------------------|------------|
| 3.x / 4.0 | Tomcat 8 / 9（`javax.*`） |
| 5.0 / 6.0 | **Tomcat 10.1 / 11**（`jakarta.*`） |

用對應的 `web.xml` 版本才不會被容器拒絕啟動。
